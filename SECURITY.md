# Security Policy

## Supported Versions
This repository is documentation-focused; always use the latest `main` branch.

## Reporting a Vulnerability
If you discover a security issue in any code I publish:
1. Do **not** open a public issue.
2. Email **bhuvanthangudu7@gmail.com** with reproduction details.
3. I aim to acknowledge within 48 hours and remediate or document within 7 days.

## Disclosure
I follow coordinated disclosure. Public writeups are published only after fixes or per program policy.
