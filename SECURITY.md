# Security Policy

## Supported Versions

Only the latest `main` branch is supported.

| Version | Supported |
|---|---|
| `main` | ✅ |
| Anything older | ❌ |

## Reporting a Vulnerability

If you find a security issue in this repository, **report it privately** —
do not open a public issue.

Use GitHub's private vulnerability reporting:
**https://github.com/bhuvanchandt/bhuvanchandt/security/advisories/new**

Expect an acknowledgement within 72 hours.

## What this repository contains

This is a GitHub profile README — it contains a profile page, documentation, and
public contact details. It intentionally contains no credentials, tokens, keys,
or internal hostnames.

## If you have found an issue with a vulnerability I reported

If you are a maintainer of a system I have reported a vulnerability to and you
need to reach me about a published writeup, contact me privately via the email
linked on my profile. I will treat the conversation confidentially.

If you are a security researcher: please report vulnerabilities in your own
authorized scope privately to those systems first. Do not open public issues on
this profile about live target vulnerabilities.
