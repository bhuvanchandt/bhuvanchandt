## About

I am a **Penetration Tester and Security Researcher** specializing in **Web Application Security, API Security, Network Penetration Testing, Vulnerability Assessment, and VAPT**.

I got into cybersecurity because I wanted to understand **how systems actually fail**, not just study vulnerabilities theoretically. My approach combines structured methodology with hands-on manual validation, allowing me to understand an application's attack surface, identify weaknesses, validate their real-world impact, and provide remediation guidance that development teams can act on.

I have worked on **20+ web application and network penetration testing engagements**, identifying and validating vulnerabilities across client environments using industry-standard security methodologies and tools. My experience includes testing for **SQL Injection, Cross-Site Scripting (XSS), IDOR, SSRF, authentication bypasses, API security issues, and other OWASP Top 10 vulnerabilities**.

I also have experience producing **15+ risk-rated vulnerability assessment reports**, translating technical findings into practical remediation steps and business-impact-focused recommendations.

### Cybersecurity Expertise

- **Web Application Security** — OWASP Top 10, SQL Injection, XSS, IDOR, SSRF and authentication bypass
- **API Security** — API vulnerability identification, authentication flaws and API security assessment
- **Network Penetration Testing** — network reconnaissance, enumeration, exploitation and attack-path analysis
- **Vulnerability Assessment & Penetration Testing** — black-box VAPT, manual validation and vulnerability exploitation
- **Reconnaissance** — attack-surface discovery, enumeration and target mapping
- **Red Team Methodology** — reconnaissance, exploitation and post-exploitation workflows
- **Manual Testing** — validating scanner findings and eliminating false positives
- **Security Research** — vulnerability discovery, exploitation analysis and attack-path research
- **Security Reporting** — risk ratings, technical evidence, impact analysis and developer-ready remediation
- **Exploit Development & Scripting** — Python-based exploit scripting and security automation
- **Security Tooling** — Burp Suite, Nmap, Metasploit, SQLmap and Nuclei

### Professional Approach

I don't just identify vulnerabilities — I focus on **validating them manually, demonstrating realistic attack paths, understanding business impact, and communicating remediation clearly**.

My objective is to help security teams and organizations understand **how an attacker could break into their systems and what engineering teams can do to prevent it**.

### Open To

`Penetration Testing` · `VAPT` · `Web Application Security` · `API Security` · `Network Security` · `Red Teaming` · `Security Research` · `Application Security` · `Cybersecurity`
