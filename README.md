## About

I'm a **Penetration Tester and Security Researcher** working across **Web Application Security, API Security, Network Penetration Testing, and VAPT**.

I got into cybersecurity because I wanted to understand **how systems actually fail**, not just study vulnerabilities theoretically. My work combines structured methodology with hands-on manual validation — mapping an application's attack surface, identifying weaknesses, proving real-world impact, and writing remediation guidance a developer can act on.

I've worked on **20+ web application and network penetration testing engagements** and produced **15+ risk-rated vulnerability assessment reports**, covering SQL Injection, XSS, IDOR, SSRF, authentication bypass, and API security issues.

> I don't stop at "this scanner flagged it." I validate it manually, build the attack path, and explain what it actually costs the business.
